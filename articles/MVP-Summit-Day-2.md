# MVP Summit - Day 2

Day 2 was all about stuff that I can't talk about. Which kind of makes this blog post pointless :), but I can say that the day went well. I had a great conversation with Eric while waiting in the lunch line - what an easy guy to talk to. He also made it crystal clear when you should use a constant:

```c#
public const int Pi = 3.14;
```
versus a static read-only:

```c#
public static readonly string Version = "1.4.1.5";
```

As the day wore on, the sessions started to lose energy, but it was probably due to the fact that I was getting tired. At the dinner (which was fun), I had to get up a couple of times and walk around. I don't mind crowds but I'm not one to just talk and talk and talk on end - I needed to get out and get some space alone for a bit. Right now I'm in the hotel room working on some code, and then I'm going to bed. I'm shot, and tomorrow night will probably be a long night, so I need to recharge.
