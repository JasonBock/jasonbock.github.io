# "Framework Design Guidelines"

I just finished this book. I started reading it months ago but I stopped because there was way too much hype from other bloggers about it, and I wanted to have the right expectation levels set for me (which is no book will ever solve every problem known to mankind). Overall it's a fine book. Some of it is blindingly obvious advice, and some of it made me stop and wonder if I really agreed with a given recommendation, and in either case, it was good to read the material. If you're new to .NET programming (or programming using a framework in general), this book is required reading, period. If you're a seasoned programmer, I think it's worth a read, even if it's a cursory, pick-and-choose kind of approach.
