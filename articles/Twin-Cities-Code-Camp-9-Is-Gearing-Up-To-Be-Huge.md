# Twin Cities Code Camp 9 is Gearing Up to be HUGE

I've been with TCCC since its inception, since ... well, I was the one that started it :). Over the last 4 years, it has grown and expanded slowly but surely. With TCCC9, it's now so big that it's 2 days long! Oct. 9th and 10th are dates this time. Frankly, the session list is awesome and I'm still taking session submissions! I'll have to make some cuts, and that sucks because the topics are relevant and interesting, but that means (hopefully) the quality and quantity will be on the high side.

Hope to see you all there! :)
