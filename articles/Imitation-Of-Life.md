# "Imitation of Life"

I finished this book on the plane last night. It's a nice introduction to biologically-based computing ideas, like evolutionary algorithms, bio-based hardware, etc. I'm no expert in these areas but I have spent some time learning about these topics before, so this was a very quick read. That's not a negative statement about the book; it's actually very good at being a high-level view of these areas. If you want to learn about evolutionary programming or neural nets, this is a nice, gentle introduction.
