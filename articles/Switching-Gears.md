# Switching Gears

For the last 2 to 3 months, I've been focused on internationalization issues in WinForms, especially as it pertains to right-to-left languages (like Arabic). That effort has pretty much finished in that we have a bunch of code in the client's framework to solve a number of issues we've found, some of which I'll talk about next week (BTW if you're in the Twin Cities area and you're coming to the talk and there's something you'd like to hear about relating to i18n in .NET let me know and I'll see what I can do as I'm putting the slide deck together over the next 7 days). Now I'm working on a piece of code that uses Remoting and WinServices - lots of fun. This is when consulting is fun: you get to enjoy a lot of different technologies. However, we also need to use ADO .NET, which isn't hard ... but I haven't touched ADO .NET in over 8 months, so the simple things are driving me nuts! Oh, well, it's nothing that I can't figure out, and the work is technically interesting, so life is good.
