# Just One Test Results Directory, Please

Is there any way to get the testing environment in VS 2005 to not create directory upon directory upon directory every time I run my tests? This is really annoying me, but I can't find any option in .testrunconfig to say, "just put the results in a directory called Results and overwrite its contents if it's already there". I understand in some scenarios you'll want to preserve the contents of a test run, but more often than not I really don't care to keep that history around.

Any suggestions?
