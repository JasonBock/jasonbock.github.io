# Finishing an ASP.NET Project, and "The Ring"

Well, I'm finally done with the ASP.NET project. I learned a lot more about ASP.NET than I did before, but the project was under such tight time constraints I didn't have the opportunity to give the application the re-working that it so desperately needs. But it was a fun project and it was a good client to work for, so it was time well-spent.

Liz and I went to see "The Ring" last night. I was impressed. Dark and moody, but it kept my interest throughout the picture. At no time was I bored or disinterested in the plot - I was pretty much hooked from the start.

Speaking of movies, supposedly on Nov. 15th there's going to be a new trailer for Terminator 3 here. Next year is going to be so much fun: T3, the two Matrix movies, the last LOTR ... "I'm in heaven ... I'm in heaven".
