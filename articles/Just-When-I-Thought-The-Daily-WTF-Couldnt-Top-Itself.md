# Just When I Thought the Daily WTF Couldn't Top Itself ...

It uncovers [this gem](https://thedailywtf.com/articles/Happy_(Belated)_Jed_Day!). Ho ... ly ... shit! I love the comment that's in the code:

```
  // if the expression is true then the result will be true, otherwise (since the
  // expression couldn't be true) the result will be false.  There are no other
  // mathematical possibilities
```

because later on it says:

```
  // need to set the result if it hasn't been set yet, we'll randomly decide true or false
  // because there should be no bias.
```

But I thought there were no other mathematical possibilities other than true or false?!

Wow. I have no other words for code like this. Just ... wow.
