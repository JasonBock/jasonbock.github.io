# Working with VB

My latest client is using VB. I haven't used VB in 2 years, so it's been interesting to see what I like and don't like about VB. I've always stated that I think the different between VB and C# is so immaterial that any discussions around "which is better" is a waste of time, and I still think that. I like some things about VB (the `With` keyword, I find it easier to read than C#) and some things I don't like (line continuations suck). But the key point is, if you're a .NET developer, you should be able to code in either C# or VB. The syntax may be different, but the concepts are the same.
