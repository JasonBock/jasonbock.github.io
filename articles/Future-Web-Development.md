# Future Web Development

That's it. I've decided to no longer update my web site in terms of HTML content. This post sums up my attitude towards web development (of course, I've stated my dismay over HTML+CSS+JS before). I'm not saying Silverlight is the answer, but it's the 21st century, and things have to get better than the current web development platform that we have.

I remember in the late 90s a big push was made to move application development towards the web. Now, 10 years later, it's time to make another big push - we need to move away from the archaic model that we have and start making applications that are fun to make, easy to deploy, and blow away our users. It's not a move back to client-server, or "smart clients" or anything like that. It's acknowledging that it's finally time to make that big jump and start getting users applications that will truly inspire them.
