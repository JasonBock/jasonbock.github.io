# RSS Bandit Woes

![RSS Bandit Woes](https://jasonbock.net/images/RSS-Bandit-Woes.png "RSS Bandit Woes")

I've been seeing this screen way too often lately. I added a bug - hopefully there will be an update of RSS Bandit soon. The latest release (1.5.0.10) is not as impressive as I was hoping it would be. There are ClearType issues, crashing issues, high memory pressure issues (still!). I really like it and I really want to keep using it (I tried Outlook 2007 for RSS management and it nearly drove me insane) but right now it's a bit flakey.
