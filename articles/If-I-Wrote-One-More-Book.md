# If I Wrote One More Book ...

I would call it "Dynamic Coding in .NET". It would be about using Reflection, emitting code at runtime, using Cecil for lots of cool things, and maybe even diving into the profiler a bit to see what can be done there. It probably would be around 150-250 pages in length.

Of course, I'm not writing a book right now, frankly because the ideas I come up with wouldn't sell a lot of copies (and I loathe the thought of writing a "Intro to C#" or "Beginning VB" books that's over 40,000 pages long and causes back spasms and hernias every time you carry one around - yuck!). e-books would make an endeavour like this more appealing ...
