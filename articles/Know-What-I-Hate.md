# Know What I Hate?

Checking the client's e-mail on a Friday night, only to find an e-mail entitled as follows:

> someone named JASON broke the build and left the building for the weekend

Sometimes I wish my boss would just stop beating around the bush and get to the point.

Grrr ... I haven't done this yet on the project - I've been on it for over a year - but it pisses me off. Fortunately we turned off the build process for the weekend anyway (for an unrelated issue) but still, that's the first thing I'm going to address when I get in on Monday. I hate doing stupid things (especially since I could've sworn the build box was green before I packed up Friday afternoon ... )
