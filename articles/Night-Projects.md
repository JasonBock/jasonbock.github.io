# Night Projects

For the last month my motivation to do anything after the kids are in bed has been at an all-time low. I'm simply too tired to stay up after 10 PM these days (of course, getting up at 5 AM isn't helping either). There are a lot of things I'd like to tinker with, like my 360 games, my musical instruments, some coding project ideas, etc., but all I have been doing is hitting the sack and reading for about an hour. Which isn't all that bad - I've been able to tear through a number of books lately (I'm currently halfway through "Snow Angels" - pretty good read so far). But I have to change things around.

I think I'm going to adjust my schedule slightly so I'm up around 5:30 or 6. That doesn't sound like much but that should help get me a couple of late-night excursions in. Music-wise ... well, the Sidetracked Project is on hiatus for the near future, and I really don't know when that's going to be revisited, so I'm going to have to find another outlet to work on material in the near-term. Games ... I admit, I'm not all that excited to play video games lately, but I do want to actually play some of the games I've purchased! Programming projects ... I have a Reflector add-in that I want to finish, and I have a VSLive presentation to give, and there's Code Camp 4, and I'm attending Lang.NET and MVP Summit, so I need to rev things up a bit in that department as well.

It's funny, Liz and I were talking last night about what it was like before we had kids. It was so much easier then - we could do whatever we wanted whenever we wanted ... but I wouldn't trade it for anything either.
