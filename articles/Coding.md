# Coding?

It's dawned on me today that I may not write one line of code for the client for the next three months. That's not good. I don't think I could ever stop coding - there's always something satisfying about actually producing something that works. That being the case, I'm going to have to start to focus on my side projects at night to make sure I keep my skills up. I also need to get my guitar and keyboard parts for the Sidetracked Project, and I have a bunch of little house fixes I need to address. That means the deck has been delayed for another year. I'm disappointed with this, but something had to give, and I really want to get the music stuff done before out second child is born.
