# Need to Add Web Services

Since I did the last update to my site, I've realized that I need to change things around again and move to a - dare I say it? - SOA model (ack! barf! buzzword alert!!) Seriously, though - the last change has the UI tied to the DB hard enough that I can't use it at the client, and this web form I hacked up to allow me to add new blog entries is just not cutting it. My custom WinForms tool is completely tailored for what I want to do, and I miss all the little shortcuts I've made. So, I'm going to add some services so I can easily update my blog no matter where I'm at.

Of course, this also means I have to ensure the blog management tool has good security around it so only I can update the content, but anyone could retrieve the most popular entries, or the latest comments, etc. Don't know when I'll get around to doing this, but it's just another thing to add to the ever-growing TODO list.
