# "Empyrion" Mix

When I logged on tonight, I got a nice treat from Mike - the first version of the final mix for "Empyrion."

Damn.

It's hot.

Like, **smoking** hot.

I've had this tune on the back burner for nearly 16 years, so hear it in its entirety (it's over 18 minutes long) is pure joy. It still need some tweaks here and there, but I think you'll like it when we finally release it.
