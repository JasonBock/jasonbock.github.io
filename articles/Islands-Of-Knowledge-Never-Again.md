# Islands of Knowledge - Never Again

This sucks. My current project has run into an issue where one of the developers knew everything there is to know about the build, but since he just had a baby yesterday none of us know all the little things he did to get it to work. It's not hard, but because we've ended up with the knowledge islands, we're hurting a bit more than if we kept switching the developers around so they all know the system as a whole.

The sad thing is that on my previous project we didn't have this problem as everyone did everything. But, due to reasons that went beyond my control, we ended up in the situation we're in. Oh, well. All I can say is, this will never happen again, at least if I can help it!
