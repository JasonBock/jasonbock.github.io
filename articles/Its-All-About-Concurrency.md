# It's All About Concurrency

Last night I gave an internal talk at Magenic's office on concurrency. I'll be giving the same talk (more or less) at a future Twin Cities User Group meeting (Dec. 2006). I've always had an interest in multithreading and parallel processing (although I'm definitely no "expert" on it). These days, with multi-core chips, it seems like concurrency is a fairly hot topic again (at least on the blogs I read!).

Today I read about PLINQ. Wow. How cool would this be? I'm all for making concurrent programming as easy as writing a for loop, and I hope this makes parallel queries painless and seamless.
