# Windows Is The Problem

I had IE7 crash on me this morning, and when I clicked on the "More Information" link that I got after reporting the error information, here's what I saw:

![Windows Is The Problem](https://jasonbock.net/images/Windows-Is-The-Problem.png "Windows Is The Problem")

I quote:

> This problem was caused by Windows, which was created by Microsoft Corporation. There is no solution for this problem at this time.

That made me chuckle pretty hard.
