# PGR3 Tourney Status: Getting Closer

Last night I improved my time to 54:43 so I shaved almost a second off of my previous best time. The cutoff time moved down a bit to 54:09, but now I'm around 125th position. I think it's still possible for me to qualify, but it's going to be hard. I've noticed that even if I don't post a better time there are sections and turns that I sometimes do a bit faster than my best time, but it's a matter of pulling it all together in one run. I think qualifying runs through May 2nd so we'll see how things go. Personally, I think that I'll have to turn in a time under 54 seconds to have a shot - I think the cutoff time is going to go under 54 seconds, easily.

What sucks is that I haven't been able to find a leaderboard for the tournament qualifiers. Maybe it's online somewhere, but I haven't been able to find it in the game. It would be nice to see what the standings are ... somewhere ...
