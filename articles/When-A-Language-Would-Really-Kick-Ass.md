# When a Language Would Really Kick-Ass

[Scott discusses](https://www.hanselman.com/blog/programmer-intent-or-what-youre-not-getting-about-ruby-and-why-its-the-tits) Ruby and programmer intention. He gives an example of getting the time 20 minutes ago and how you would do this in Java and Ruby. Sure, 20.minutes.ago in Ruby looks nice, but what I really want is this:

```
20 minutes ago
```

No semi-colons. No curly braces. No dots. No colons. How about a programming languages that speaks human language? I know, that's pie-in-the-sky, way too difficult, stupid idea, etc., etc. But it would be really nice to write programs without having to learn a new syntax all the time.
