# Compiler Lab 2006 - Day 2

Yesterday there were talks about IronPython, scripting, F#, Phalanger, and APL. Wow, is APL one of the most confusing languages I have ever seen! Some of the off-line discussions were interesting as well. Unfortunately, I won't be able to have a Day 3 report. I think I finally got what Liz had last weekend. I'm feeling better now, but I'm still really weak, so I'm sitting in the hotel room, doing as little as possible. I want to get over this enough so I can make my flight Friday morning.

I think this Compiler Lab was interesting. I doubt I'll attend another, but it was still worth the time to attend the sessions. The F# presentation was really cool - I need to spend some time to get familiar with this language. For compiler developers, I think it's definitely worth it to attend these sessions.
