# "An Alien Light" and "Waiter Rant"

OK, I have to admit, I had a blog post all polished up, ready to be delivered to my web server ... only for me to accidentally wipe it away, never to be seen again. And frankly, I'm too lazy to write it all up again. So I'll sum it up this way:

* "An Alien Light" - sci-fi book about an alien race trying to figure out humans. OK ... not great, but not bad either.
* "Waiter Rant" - stories from the restaurant trenches, written by a waiter. **Highly** recommended - I was laughing my ass off, but I also some some heart and humanity in the tales of human arrogance and insanity.
