# Moving to Minnesota

Life has some major changes coming up. Liz and I are moving to Minnesota next week - I'll be working for a consulting company called Magenic. I'm excited to move to a new area, but at the same time it's been difficult. I'm also working on some new writing projects and that's been sucking up time when I'm not packing my stuff in boxes. When I finally get set up next week, I'll be going dark for a while as I try to finish these projects.
