# Doing .NET Remoting

I was doing some .NET Remoting work today - nothing hard-core, but it was still fun (BTW get Tom's distributed programming or Ingo's Remoting book - they're great resources. Anyway, Ingo mentioned the WinCV tool that comes with .NET - it's a nice tool to find out information about your class. So the next time someone asks, "where's this class located," tell 'em to WinCV (or open the SDK - that works too ;) ).
