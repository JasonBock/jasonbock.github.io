# I Think I Killed It

I tried to run another game against this [Quixo](https://github.com/JasonBock/Quixo) game. Here's where I stopped the madness:

![Quixo Lockup](https://jasonbock.net/images/Quixo-Lockup.png "Quixo Lockup")

The rival program locked up for over a half-hour trying to generate a response, and I couldn't wait that long while it completely tied up my CPU. I think I need to find a different rival that doesn't cause my computer fan to fire up every time it's coming up with a new move.
