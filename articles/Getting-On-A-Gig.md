# Getting on a Gig

For the last month or so, I've either been on a so-so gig (wasn't very technically challenging) or on the bench. Frankly, my attitude has went a bit south in a number of ways. I thrive on learning new things and when I'm doing the same thing I did before or I'm not doing anything on my job ... it gets tiresome. Thankfully, I'll be starting a new gig very soon - hopefully there will be some interesting challenges to go along with it.
