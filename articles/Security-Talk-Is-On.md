# Security Talk is On

I have to admit that I felt really ... well, "odd" that I didn't do my security talk last week. It felt anti-climatic. Sure, I was "off the hook", but I put so much time into putting the material together and it was pretty much all for nothing. So I talked to the client about giving the presentation as a brown-bag 1-hour session and they said, "sure!". Now I'm not done until June 5th, but I feel a lot better about things. I can present the material, and I've already practiced for it so prep time will be minimal. Then I can feel like the weight has truly been lifted and enjoy the summer.
