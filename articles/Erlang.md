# Erlang

I've tried to spend some time learning Erlang. I think the ideas it presents are interesting, but something about the syntax screams "butt-ugly" to me. That really shouldn't matter, but it's getting in the way. Frankly, F# has a lot of interesting tidbits (even related to concurrent programming) so I don't think I'll be spending any more time with Erlang.
