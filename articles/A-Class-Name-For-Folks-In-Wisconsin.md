# A Class Name for Folks In Wisconsin

Today is a good day.

I get to write the `Bubbler` class.

Those in Wisconsin (especially around the Milwaukee area) will get it. I still love asking people, "where's the bubbler" and getting this look of complete befuddlement on their faces.
