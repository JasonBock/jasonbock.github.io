# Fun With VS .NET 2005

Well, I'm about 65% done with converting a 1.x .NET project over to 2.0. I find this to be an easy way to get up to speed on the next version of a technology. I'm trying to include all the additions/improvements that 2.0 has to offer, but there's so much there that I might be missing some things. Plus, for some reason the help doesn't seem to be installed quite right, so that's limiting me as well. Once I get done with the conversion I may convert a couple other libraries over (and I'll make sure I let you all know when and where you can get the code drops).
