# What Now?

This morning, I started thinking about what I want to do this year. I'm giving up on resolutions - I think it makes more sense to have a dynamic, evolving set of goals, rather than a fixed set. Anyway, with Ryan on the scenes, my time is going to be pretty limited this year to do a lot of things, but here's what I hope to work on in the near future:

**Get the Deck Done** - I've delayed this project for the last two years, and I don't want to get a third strike this year. I want to start early May and hopefully have it all done early summer. Actually, I should rephrase this goal - I **have** to get this done!

**Finish the Sidetracked Project Music** - I've mentioned this endeavour many times before. We're getting very close to completion. I hope that we can have downloadable songs available to the public by March.

**Organize Another Twin Cities Code Camp** - Nothing's for certain yet, but expect an announcement on the site soon. The target date is April 28th, but that's not set in stone.

**Side Development Projects** - After I finished my dynamic proxies code...I started to wonder, what can I work on next? I need to make some fixes to my blogging engine, and I also need to address a minor bug with the file generator plug in for Reflector. But, after that, I'm not really sure what I'm going to do this year. WCF, WPF, WW and Phoenix seem like some interesting APIs to dive into, but we'll see. I have a list of todo's somewhere - I think I need to resurrect that.

**Speaking Engagements** - Right now the only thing scheduled is a talk in March for the Chippewa Falls .NET User's Group. I might do a talk for the next Twin Cities Code Camp, but I may focus on organizing it.

**Daytime Activites** - I've been an employee for Magenic now for 6 years. That's the longest I've ever been with a company, and at this point I don't see a reason to depart. Over the last year I've decided to be more involved with the organization and I hope to continue that.

I'll see what I can get done!
