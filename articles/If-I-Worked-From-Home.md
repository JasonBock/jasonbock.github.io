# If I Worked From Home ...

I'd already be at the office.

Occasionally I cover the issue of working from home. I was able to do it a couple of years ago for a project I was on, and it went very well. Sometimes I wish I could do that again. If I was doing it now, it would save an hour's worth of communting time for me every day. I'd also be saving a lot of money on gas. But, our project is an agile-based one and we do pair programming, so ... how does one pair when they're not physically there? I know, set up something so people could virtually share desktops and/or use webcams, but I don't know how well that would work.

I don't think I could ever be on a project that was 100% at-home. Client interaction is essential. But I also wonder if people have looked at potential economic and environmental benefits if employees/consultants would be allowed to work at home for a given percentage of time. And I know my current manager at my client reads my blog so I'm sure he'll make some comment about what I just wrote about :).
