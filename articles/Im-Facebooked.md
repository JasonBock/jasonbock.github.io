# I'm Facebooked

Yes, I finally decided to try out one of these crazy all-the-kids-are-doing-it social network thingees. It's actually kind of nice - I like the presentation of the site and it's pretty easy to find people. I've been able to add some nieces and nephews as well, which is pretty cool.

I have to admit, though ... I kind of feel **old** out there ...
