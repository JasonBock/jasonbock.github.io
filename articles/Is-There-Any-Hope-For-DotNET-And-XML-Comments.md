# Is There Any Hope For .NET and XML Comments?

First, there was NDoc.

That died, because Sandcastle was released.

But there's been no work on it since the October 2007 release (as far as I can see).

This is one area in .NET that still floors me. It's been nearly 6 years since .NET 1.0 was released to the world, and we still don't have a decent tool to generated CHM files? There's MSBuild, MSTest, etc. (and you can argue how effective they are, but they are there), why isn't there MSDoc/Sandcastle 1.0?

Or was Sandcastle released and I'm just missing it?
