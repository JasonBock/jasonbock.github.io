# Considering a New Web Host

OrcsWeb is getting far too expensive these days. Their service is stellar but frankly I'm finding it harder and harder to justify the cost anymore. I'm starting to consider if I should pack it up and move somewhere else that's not so painful in the pocketbook. If you have any suggestions feel free to leave a comment.
