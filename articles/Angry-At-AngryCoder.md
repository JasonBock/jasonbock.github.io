# Angry at angryCoder

OK, so I'm trying to add a comment to an article. I try to sign up to the site, and after getting a bunch of annoying "Please enter a different user name" error messages where the is no user name field on the form (there's Profile Name and Login ID fields, but nothing explicitly called User Name - c'mon people, get that right!), I find out that my e-mail address is already in use. Fine, I must've created an account on the site a while ago. But ... is there any way to get my credentials via e-mail? Hell no - the only option you get from here is "Forgot your password? Click here to retrieve it". But on the next page you need your user name. Argh! I don't know what that is, but I do know what my e-mail address is - maybe you can give me the option to use that to get account information?

Sheesh.

Grrrrrrr ... angryCoder really pissed me off this morning.
