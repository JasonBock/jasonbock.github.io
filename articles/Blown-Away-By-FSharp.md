# Blown Away by F#

I've decided to spend some time perusing and understanding F#. Don Syme is releasing chapters to his upcoming "Expert F#" book so people can read the content and make comments on it before it's "set in stone". I went through Chapter 2 and now I'm Chapter 3 ... and ... wow. That's all I can say ... **wow**! I had no idea how powerful functional programming can be, and the fact that F# mixes FP with OO with ease is just unbelievable.

Of course, it's not enough to just read about a language; I need to spend some time coding in it. Hopefully I can find a project where I can force myself to do it all in F# to see just how easy/hard it is to use it. But right now, I'm very impressed with how easy it is to apply functions to data and vice-versa and be able to do some amazing things.
