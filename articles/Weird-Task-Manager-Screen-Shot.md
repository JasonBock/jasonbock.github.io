# Weird Task Manager Screen Shot

This morning my machine at the client started acting really screwy - the keyboard and mouse got all messed up and I couldn't switch between programs. A hard shutdown fixed it, but before I did that I took a look at Task Manager and this is what I saw:

![Weird Task Manager](https://jasonbock.net/images/Weird-Task-Manager.png "Weird Task Manager")

Wow - I wasn't using any memory! In fact, there were no handles, no threads - no wonder nothing worked. I think my computer was meditating and hit cosmic bliss, which is why everything disappeared.
