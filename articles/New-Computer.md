# New Computer

I finally picked up my new laptop from Magenic this morning. Every 3 years, Magenic upgrades their consultant's laptops (they usually do a "mid-term" hardware upgrade as well), and this one is pretty nice. I'm going to dump RSS Bandit and try using the new RSS features in Outlook 2007. Right now, I have to admit that I'm not impressed with their feature set, but frankly RSS Bandit is getting too piggish for my tastes, so I'm going to force myself to try something different. Unfortunately, I wrote a plug-in for RSS Bandit to allow myself to rate blog posts (which is what you see here), so I'm going to have to dive into VSTO and get the plug-in to work there (if I can!).
