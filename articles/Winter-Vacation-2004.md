# Winter Vacation 2004

OK, I'm back.

I know, you were all on pins and needles waiting for an update. Well ... I really don't have much to say. It was fun, there was a bit of family drama (as there usually is), I ate more than what I wanted to (I actually fell asleep Christmas day, which I've **never** done before), I freaked out a bit about the reality that I will be a father soon and I know **nothing** about being a parent (a common reaction that most first parents get I've been told) and I got a lot of cool stuff (the 500 poker chip set was sweet). Right now I'm waiting for dinner (pizza) to be delivered and then I'm playing some XBox, so I probably won't post more tonight, but I'll answer some e-mails about previous posts later, and I'll get back into the online mode by tomorrow.
