# No Constant Values?

As I was working in VS .NET 2003 today, I noticed that the Object Browser doesn't show constant values, which in my mind sucks rocks. Reflector does it ... why doesn't VS .NET 2003? Thinking that this was just a minor bug, I fired up VS .NET 2005 (Beta 2) and, lo and behold, constant values are still not shown in the Object Browser!

Is there some configuration value in VS .NET that I have to set so I can see constant values? I just can't believe the browser won't show constant values - there's gotta be a way to do it ...
