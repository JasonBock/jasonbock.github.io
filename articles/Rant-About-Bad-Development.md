# Rant About Bad Development

Right now I'm refactoring JavaScript in our application. I have one page left, but the JavaScript is nightmarish. Lots of functions just dangling out there, grabbing crap willy-nilly ... it's just not cohesive, nor is it easy to follow.

I hate it when I run into code like this. I'm only 36 years old and I'm getting tired of this crap. It's 2007 - there are ways to write code that's maintainable and easy to read. This really has nothing to do with JavaScript; it's this idea that, "hey, I'll just slap a function in there and tie the event - it works, yeah! I'm moving on ... " Too bad others have to read that code and scratch their heads, desperately trying to figure out what the hell is going on.

OK, rant over.
